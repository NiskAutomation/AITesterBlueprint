# Chapter 01: LLM Basics

This folder contains visual and interactive explainers for foundational Large Language Model (LLM) concepts.

## Contents

| File | Description |
|------|-------------|
| `attention_is_all_you_need.html` | Visual explainer of the Transformer architecture (from the seminal "Attention Is All You Need" paper). |
| `attention_interactive.html` | Interactive demo that lets you explore how attention mechanisms work. |

## How to use

Open the HTML files directly in a browser, or serve the repository root with a local HTTP server:

```powershell
python -m http.server 8000
# Then navigate to: http://localhost:8000/Chapter_01_LLM_Basics/attention_is_all_you_need.html
```
