# Chapter 02: Prompt Engineering

This chapter focuses on **prompt engineering for test automation and AI-assisted QA**. It includes hands-on projects, reusable prompt templates, and production-ready automation frameworks generated with AI assistance.

## Projects

| Project | Description |
|---------|-------------|
| **Project1_TC_Gen** | Test-case generation for the Restful Booker API using the RICE-POT prompt framework. |
| **Project2** | Prompt engineering skill definitions, anti-hallucination guardrails, reusable templates, and two reference automation frameworks (Playwright & Selenium). |

## Key Concepts Covered

- Structured prompt building (RICE-POT framework)
- Anti-hallucination rules for deterministic AI output
- Generating page-object models and test suites from prompts
- Reusable prompt templates for functional, API, negative, security, and regression testing
