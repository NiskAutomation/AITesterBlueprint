# Project 2: Prompt Engineering & Automation Frameworks

This project is the core workspace for **advanced prompt engineering** and **AI-assisted test automation**. It includes skill definitions, anti-hallucination rules, reusable templates, and two production-ready reference frameworks.

## Contents

| File / Folder | Description |
|---------------|-------------|
| `SKILL.md` | RICE-POT Prompt Builder skill definition — a complete guide to interviewing users and assembling structured prompts. |
| `Problem.md` | Problem statement for generating a Selenium automation framework from scratch. |
| `Anti_Hallucinations_Rules.md` | Guardrails to ensure deterministic, traceable, and hallucination-free AI output. |
| `blank-template-rice-pot.md` | Empty fill-in template for quickly drafting RICE-POT prompts. |
| `Templates/` | Reusable prompt templates for common testing tasks (test case generation, API tests, security tests, regression suites, etc.). |
| `AdvancePlaywrightFramework/` | TypeScript-based Playwright automation framework with Allure reporting. |
| `AdvanceSeleniumFramework/` | Java-based Selenium + TestNG automation framework for Salesforce login testing. |

## Quick Start

1. Review `SKILL.md` to master the RICE-POT prompt-building workflow.
2. Apply the `Anti_Hallucinations_Rules.md` guardrails to any testing prompt.
3. Pick a template from `Templates/` and customize it for your project.
4. Use the automation frameworks as reference architectures or starting points.
