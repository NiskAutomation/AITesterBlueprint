# Project 1: Test Case Generation (TC Gen)

This project demonstrates how to use the **RICE-POT prompt framework** to generate comprehensive test cases for the **Restful Booker API**.

## Contents

| File / Folder | Description |
|---------------|-------------|
| `Restful-booker.pdf` | Reference documentation / requirements for the Restful Booker API. |
| `RICE_POT_FRAMEWORK/` | RICE-POT framework templates and guidelines used to structure the prompts. |
| `output/` | AI-generated test case artifacts produced from the structured prompts. |

## Workflow

1. Study the `Restful-booker.pdf` requirements.
2. Use the RICE-POT framework templates in `RICE_POT_FRAMEWORK/` to build a structured prompt.
3. Feed the prompt to an LLM to generate exhaustive test cases.
4. Review and refine the generated artifacts stored in `output/`.
