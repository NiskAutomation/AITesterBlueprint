# RICE-POT Framework

This folder contains the **RICE-POT prompt framework** assets used to generate high-quality, deterministic test cases.

## What is RICE-POT?

A structured prompt-building methodology where each letter stands for a critical component:

| Letter | Component | Purpose |
|--------|-----------|---------|
| **R** | Role | Persona the AI should adopt |
| **I** | Instructions | Step-by-step commands and guardrails |
| **C** | Context | Background, product details, and inputs |
| **E** | Example | Sample output format to guide style |
| **P** | Parameters | Quality constraints and accuracy rules |
| **O** | Output | Exact artifact and format to produce |
| **T** | Tone | Communication style |

## Contents

| File | Description |
|------|-------------|
| `RICE_POT_Guidelines.md` | Detailed guidelines on how to apply the RICE-POT framework. |
| `RICE_POT_Template.md` | Fill-in-the-blank template for constructing prompts. |

## How to use

1. Open the guidelines to understand each component.
2. Copy the template and fill in each section based on your testing requirements.
3. Use the finished prompt with your preferred LLM.
